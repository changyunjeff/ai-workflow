# Rotating API keys

API keys do not expire on their own. You should rotate them at least every 90 days, and immediately if you suspect a key has leaked.

## Before you start

Rotation creates a new key and schedules the old one for deletion. Both keys work during the grace period, which defaults to 24 hours. Use this window to deploy the new key to every service that calls the API.

## Steps

1. Run `keyctl rotate --name <KEY_NAME>` to create the new key. The command prints the new secret once; it cannot be retrieved later.
2. Update the `API_KEY` environment variable in each service and redeploy.
3. Check that no requests are still using the old key: `keyctl usage --name <KEY_NAME> --old`.
4. If the count is zero, end the grace period early with `keyctl revoke --old`. Otherwise wait for the remaining callers to be updated.

Never commit a key to source control. If you did, treat the key as leaked: rotate it now, then remove it from the repository history.
